## File Contents Plan

### Coordination Files

1. **COCO.md** — Project overview, Snowflake connection info, what CoCo owns, current status, \"read .agents/HANDOFF.md for latest state\"
2. **CLAUDE.md** — Same project overview, what Claude Code owns, current status, pointer to handoff file
3. **.agents/HANDOFF.md** — Structured sections: `## Latest from CoCo`, `## Latest from Claude Code`, `## Blocked`, `## Ready for Handoff`. Each agent updates its section.
4. **.agents/TASKS.md** — Full task list with `[COCO]`/`[CLAUDE]`/`[EITHER]` ownership tags and `[ ]`/`[x]` checkboxes
5. **.agents/DECISIONS.md** — ADR-lite format for key choices (data model, metric formulas, tech stack)

### CoCo-Owned Files (SQL + Semantic + Agent)
6-12. **sql/** — Numbered execution order, each file is self-contained and idempotent
13. **semantic/supply_chain.yaml** — Semantic view with entities, relationships, metrics, time dimensions
14. **semantic/verified_queries/** — VQR YAML for the four canonical metrics
15. **agent/supply_chain_agent.yaml** — Cortex Agent wired to the semantic view

### Claude Code-Owned Files (App + Tests + Demo)
16. **app/streamlit_app.py** — Persona-switching demo app
