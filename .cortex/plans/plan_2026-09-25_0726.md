### Implementation Plan: Task B04 — Statistical Data Generation (Masters & Transactions)

#### 1. Context & Objectives
Task B04 populates the 9 source tables in `SUPPLY_CHAIN_FORGE` with statistically calibrated supply chain data matching `docs/LLD.md` §3, `docs/CONTRACT.md` §3, and `docs/GAPS_RESOLVED.md` GAP-6:
- Master entities loaded first, followed by transactional entities in strict Foreign Key order.
- Generates realistic enterprise volume targets (~12,000 total rows) using native Snowflake functions (`GENERATOR`, `UNIFORM`, `RANDOM`).
- Calibrated to satisfy the canonical metric ranges:
  - **On-Time Delivery (OTD)**: 84% – 90% (target ~87%)
  - **Order Fill Rate**: 90% – 95% (target ~93%)
  - **Days of Inventory (DOI)**: 15 – 45 days (target ~28 days)
  - **Avg Landed Cost**: $150 – $900 (target ~$412)
- Injects deliberate real-world edge cases and divergence hooks:
  - **Date Conflict**: ~20% of orders have `VBAK.ERDAT` (ERP date) differing from `VTTK.PROM_DLV_DT` (TMS date).
  - **In-Transit Shipments**: ~8% of shipments have `ACT_DLV_DT = NULL` with status `IN_TRANSIT`.
  - **Cancelled Orders**: ~5% of orders marked `CANCELLED`.
  - **Partial Fulfillments**: ~15% of order lines shipped partially (`QTY_SHIPPED < KWMENG`).
  - **Data Hygiene Constraints**: Strict `QTY_SHIPPED <= KWMENG` (zero overshipping) and exactly 1 primary supplier per part.

#### 3. Verification Queries
```sql
USE DATABASE SUPPLY_CHAIN_FORGE;

-- 1. Row counts vs targets
SELECT 'LFA1' AS tbl, COUNT(*) AS cnt, 60 AS target FROM SRM_SOURCE.LFA1
UNION ALL SELECT 'MARA', COUNT(*), 250 FROM SRM_SOURCE.MARA
UNION ALL SELECT 'SOURCING', COUNT(*), 400 FROM SRM_SOURCE.SOURCING
UNION ALL SELECT 'T001W', COUNT(*), 12 FROM WMS_SOURCE.T001W
UNION ALL SELECT 'KNA1', COUNT(*), 120 FROM ERP_SOURCE.KNA1
UNION ALL SELECT 'VBAK', COUNT(*), 800 FROM ERP_SOURCE.VBAK
UNION ALL SELECT 'VBAP', COUNT(*), 2400 FROM ERP_SOURCE.VBAP
UNION ALL SELECT 'VTTK', COUNT(*), 900 FROM TMS_SOURCE.VTTK
UNION ALL SELECT 'MARD', COUNT(*), 9000 FROM WMS_SOURCE.MARD;

-- 2. Raw Metric Sanity Checks
-- OTD (target: 0.84 - 0.90)
SELECT COUNT_IF(ACT_DLV_DT <= PROM_DLV_DT) / COUNT_IF(ACT_DLV_DT IS NOT NULL) AS raw_otd FROM TMS_SOURCE.VTTK;

-- Fill Rate (target: 0.90 - 0.95)
SELECT SUM(QTY_SHIPPED) / SUM(KWMENG) AS raw_fill_rate FROM ERP_SOURCE.VBAP WHERE QTY_SHIPPED > 0;

-- DOI (target: 15 - 45)
SELECT AVG(LABST / NULLIFZERO(DAILY_USG)) AS raw_doi FROM WMS_SOURCE.MARD;

-- Date Discrepancy Rate (target: 0.15 - 0.25)
SELECT COUNT_IF(s.PROM_DLV_DT != o.ERDAT) / COUNT(*) AS date_conflict_rate
FROM TMS_SOURCE.VTTK s
JOIN ERP_SOURCE.VBAK o ON s.VBELN = o.VBELN;
```
