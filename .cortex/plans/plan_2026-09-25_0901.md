### Implementation Plan: Task B06 — Governance Object Tags & Dynamic Column Masking Policies

#### 1. Context & Objectives
Task B06 establishes the data governance layer in `SUPPLY_CHAIN_FORGE.GOVERNED` according to `docs/CONTRACT.md` §6, §6a, `docs/LLD.md` §5, and `.agents/tasks/coco/B06_tags_masking.md`:
- **5 Governance Object Tags**: `ENTITY_TYPE`, `SOURCE_SYSTEM`, `SENSITIVITY`, `PII`, and `METRIC_FAMILY` with allowed value lists.
- **4 Dynamic Column Masking Policies**:
  1. `MASK_SUPPLIER_COST` (`NUMBER(12,2)`): Visible to `FORGE_ADMIN` and `BUYER_ROLE`; returns `NULL` for `PLANNER_ROLE` & `LOGISTICS_ROLE`.
  2. `MASK_PAYMENT_TERMS` (`VARCHAR`): Visible to `FORGE_ADMIN` and `BUYER_ROLE`; returns `'*** RESTRICTED ***'` for others.
  3. `MASK_CUSTOMER_PII` (`VARCHAR`): Visible to `FORGE_ADMIN`, `PLANNER_ROLE`, and `LOGISTICS_ROLE`; returns `'*** MASKED ***'` for `BUYER_ROLE`.
  4. `MASK_CREDIT_LIMIT` (`NUMBER(15,2)`): Visible only to `FORGE_ADMIN`; returns `NULL` for all three persona roles.
- **Context Evaluation Rule (§6a)**: Masking policies evaluate `CURRENT_ROLE()` so owner's-rights stored procedures (`EXECUTE AS OWNER`) execute with genuine persona context.
- **Tag Application**: Apply governance tags to source tables and sensitive columns across `SRM_SOURCE`, `WMS_SOURCE`, `ERP_SOURCE`, and `TMS_SOURCE`.
