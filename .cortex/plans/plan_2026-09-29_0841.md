### No-collision rules (written into both task files and CLAUDE.md)

1. **One owner per file or folder.**
   - **Claude Code**: `app/`, `tests/` (incl. `tests/scale/`), `demo/`, `deploy/`, `.github/`, `docs/references/`, `README.md`, and the new folders `data_gen/`, `quality/`, `eval/`

2. **Handoff lock.**
   - When Claude Code marks a file **READY** in HANDOFF (with the expected results), it stops editing it.
   - CoCo runs it and writes `docs/artifacts/runs/<card>_run.md`: every statement's outcome, the verbatim errors, row counts, timings.
   - CoCo may apply only small fixes that block a run, and each one is shown as a diff in the run report. Then the file goes back to Claude Code.
3. **Interfaces are fixed before code.** `docs/DATA_SPEC.md` (source tables, mess catalogue, rules) and CR-006 (FQNs and signatures of the new objects) bind both sides.
4. **Shared tracking files**: each agent edits only its own sections of NEXT and HANDOFF.
